# Recomendador de Documentos Top-K con Similitud del Coseno

## Objetivo
Este proyecto implementa un sistema de recomendación de documentos basado en contenido en Python utilizando vectorización **TF-IDF** y **similitud del coseno**. A partir del identificador (`id`) de un documento semilla o de una consulta en texto libre, el sistema recupera los 5 documentos más similares (`Top-5`) dentro de un repositorio organizacional.

## Dependencias
- Python 3.8 o superior
- `pandas`
- `scikit-learn`
